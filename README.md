## 🌱 Featured Project

### Sicilia‑soil · Open Farm Monitoring

[![Live Demo](https://img.shields.io/badge/Live_Demo-2d5a27?style=flat&logo=vercel&logoColor=white)](https://sicilia-soil-web-xg8w.vercel.app/)
[![GitHub Repo](https://img.shields.io/badge/GitHub-181717?style=flat&logo=github&logoColor=white)](https://github.com/carmen-buendia/sicilia-soil-web)

**Real-time monitoring dashboard for a permaculture farm in Sicily**

- **Problem:** Farmers lack real-time soil data — irrigating based on intuition wastes up to 30% of water.
- **Solution:** End-to-end IoT ecosystem: Arduino sensors → Express + MongoDB backend → Next.js 3D frontend.
- **Impact:** 25% estimated water reduction, remote monitoring of multiple parcels.

**Stack:** React 18 · Next.js · TypeScript · Three.js · Tailwind CSS · Express.js · MongoDB · Arduino · Jest

**Deployed:** Frontend on Vercel · Backend on Render · Open Source (MIT)
